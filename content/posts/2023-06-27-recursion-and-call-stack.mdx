## 재귀함수 (Recursive Function)

재귀함수는 자기 자신을 재참조하여 문제를 수행하는 함수다. [geeksforgeeks](https://www.geeksforgeeks.org/recursive-functions/)의 정의를 빌리면, 직접 또는 간접적으로 자신을 호출하는 루틴이다.

`for`문이나 `while`문을 쓰는 대신 재귀함수를 쓰면 가독성이 높아지고, 자연스레 재사용성을 도모할 수 있다. 다만 함수를 끝내는 base case가 반드시 수반되어야 stack이 overflow 되는 것을 방지할 수 있다.

다음은 재귀함수의 예시다.

```js
function func(count) {
  if (count > 0) {
    console.log(count, '현재');
    func(count - 1);
  }
  console.log('결과', count);
}

func(3);
```

```text
3 현재
2 현재
1 현재
결과 0
결과 1
결과 2
결과 3
```

`func(3)`이 호출되고 `if`문 내부의 `count - 1`인 2를 인자로 `func(2)`가 실행된다. `if`문 내부는 `count`가 0이 되기 전까지 진입하게 된다. `count`가 0이 되면 console에 `결과 0`만 찍힐 거라 예상했는데 `결과 0`부터 `결과 3`까지 모두 출력되는 걸 볼 수 있다. 게다가 역순으로 출력되었다.

콜스택의 동작원리를 보면 알 수 있다.

재귀 함수에서 함수 호출이 일어날 때마다 해당 함수의 호출 정보가 콜스택에 쌓인다. 쌓인 정보는 그 호출이 자기 코드를 끝까지 실행하고 반환할 때 제거되는데, 마지막에 쌓인 것이 먼저 제거되므로 제거되는 순서는 쌓인 순서의 역순이다.

`console.log('결과', count)`는 재귀 호출 **뒤에** 있다. 그래서 `func(3)`의 이 줄은 안쪽 `func(2)`가 반환된 뒤에야 차례가 온다. 가장 안쪽인 `func(0)`이 먼저 자기 줄을 찍고 반환하고, 그 위에 걸려 있던 호출들이 순서대로 풀리면서 `결과 1`, `결과 2`, `결과 3`이 이어진다.

## 정리

- 재귀함수는 자기 자신을 호출하는 함수이고, base case가 없으면 스택이 넘친다
- 호출마다 콜스택에 호출 정보가 쌓이고, 마지막에 쌓인 것이 먼저 제거된다
- 재귀 호출 뒤에 있는 코드는 안쪽 호출이 모두 반환된 뒤에 실행된다 — 그래서 역순으로 보인다
